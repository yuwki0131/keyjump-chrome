# KeyJump Chrome Extension

KeyJump is a simple AceJump-inspired extension that lets you open links using the keyboard.

## Features

- Press the configured keyboard shortcut to show letter markers on every visible link in the page.
- Type the letters shown on a marker to follow that link.
- Press `Esc` to cancel markers.

The default shortcut is `Ctrl+Shift+;` but you can change it from Chrome's extension shortcuts page.

## Development

The extension source is located in `src/`. To load the extension in Chrome:

1. Open `chrome://extensions`.
2. Enable "Developer mode".
3. Click "Load unpacked" and select the `src` folder.
